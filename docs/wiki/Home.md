# EmuHub iOS Wiki

The iPhone and iPad client for **EmuHub itself**, including its supported
emulator integrations. Not a standalone emulator.

Native library browsing, system-specific touch controls, and native runtime integration for EmuHub.

## Status and ownership

This is a documentation preview. Public client source and binary releases are
pending. Mapping tables are source-reviewed, not blanket device certifications.

[Repository](https://github.com/gr33k/emuhub-ios) | [Report an issue](https://github.com/gr33k/emuhub-ios/issues) | [Security](https://github.com/gr33k/emuhub-ios/security)

Wiki sources live in the repository's `docs/wiki/` directory and should be
updated through reviewed pull requests. ARMSX3 and other reusable cores retain
their own repositories, releases, and branding.
